# Smart Greeting System

A Python utility that uses the built-in `datetime` module to detect the current system time and display a time-based greeting.

## Overview

The Smart Greeting System demonstrates how Python can work with system time and conditional logic to generate greetings based on the current time of day.

## Features

- Retrieves the current system time
- Uses Python's `datetime` module
- Provides time-based greetings
- Demonstrates conditional statements
- Simple command-line implementation

## Technologies Used

- Python 3
- `datetime` module

## How to Run

```bash
python main.py
